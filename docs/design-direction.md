# Design direction

Which gallery direction this site started from, what was kept from it, and what was changed to make it this business's own. Written at setup (`site-setup/GUIDE.md` step 2a-ii), read on every build item (`tasks/CONTEXT.md`) and every maintenance change that adds a section (`ops/CONTEXT.md`).

**No color values in this file.** Describe color by role and in words ("dark band, one warm accent, light background"). The values live only in `design-tokens.md` (`_system/conventions.md` section 8), and the pre-commit hook blocks a raw value here.

Changing the direction later is a DECISION (`_system/conventions.md` section 5): it ripples into `design-tokens.md` and every built page.
